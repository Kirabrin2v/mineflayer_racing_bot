# 🏎 Mineflayer Racing Bot  

Автоматизированный бот для конкурса **«Ботьи Бега»** на сервере [teslacraft.org](https://teslacraft.org). 

## 📖 Описание  

Идея конкурса: 
Игрок управляет не собой, а ботом — через специальные блоки команд на арене (`/swarp race`). 
Задача — провести бота по полосе препятствий и довести его до финиша быстрее других. 

Особенности: 
- Полностью автоматизированная система. 
- Управление ботом через блоки (не прямое управление). 
- Поддержка различных механик: манёвры, прыжки, ускорения. 
- Ограничение времени прохождения — **260 секунд**. 
- Призы и статистика обрабатываются автоматически. 

## 🕹 Основная механика  

1. Получите управление ботом командой: 
   ``` 
   cmd ручуп 3 
   ``` 
2. На арене (`/swarp race`) доступны блоки управления, которыми вы задаёте действия бота. 
3. Бот двигается по трассе, избегая ловушек и преград. 
4. Побеждает тот, кто быстрее доберётся до финиша


## 🛠 Техническая часть  

- Язык: **Node.js** 
- Основная библиотека: **mineflayer** 
- Логика управления разделена по модулям: 
  - контроль движения, 
  - реакция на блоки управления, 
  - система проверки прогресса.
